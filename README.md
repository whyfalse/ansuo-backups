# 密文笔记本 · 数据备份仓库

小程序「密文笔记本」的密文数据自动备份：每周五全量备份一次，滚动保留最近 10 份快照，GitHub 与 Gitee 内容完全一致、互为冗余。

备份内容全部为加密密文，**不含任何明文、密码与加密盐**——任何人都无法从本仓库读出您的笔记内容。服务停摆时，可按下方步骤自行找回数据。

## 恢复数据四步走

### ① 下载还原工具

任选一个平台下载 [tool/notebook-restore.exe](https://github.com/whyfalse/ansuo-backups/blob/main/tool/notebook-restore.exe)（GitHub）或 [tool/notebook-restore.exe](https://gitee.com/lq88888888/ansuo-backups/blob/main/tool/notebook-restore.exe)（Gitee）。Windows x64 图形界面程序，Win10/11 双击即可运行。

### ② 校验下载完整性（建议）

在 exe 所在目录打开 PowerShell 执行 `Get-FileHash .\notebook-restore.exe`，比对输出的 SHA-256 与本仓库 [checksums/SHA256SUMS](checksums/SHA256SUMS) 公布的值是否一致，确认下载未损坏。

> 哈希比对仅用于确认下载未损坏，不构成真伪证明（本备份体系无签名机制，防篡改依赖双平台仓库互为对照）。

### ③ 提前准备三样凭据

三样凭据都只能在小程序正常运行时获取，**请提前保存**：

| 凭据 | 从哪里获取 |
|---|---|
| openid | 小程序「我的」页 → openid 行 →「复制」（复制的是完整值） |
| 空间密码 | 要恢复的那个密文空间的密码 |
| 恢复秘钥 | 小程序「我的」页 →「恢复秘钥」；初始化空间 / 修改密码 / 重置秘钥时也会展示。24 位短文本，可整段粘贴（附带 scrypt-* 参数亦可） |

### ④ 运行工具开始恢复

1. 双击运行 `notebook-restore.exe`，进入「恢复输入」页；
2. 选择数据获取模式——默认「指向已下载的备份仓库目录」：先在本仓库网页点绿色 **Code → Download ZIP** 下载整仓并解压，再在工具中选中该目录；也可改选「在线按需下载」，由工具自动从网络获取（只下载需要的少量文件）；
3. 填入 openid、空间密码、恢复秘钥，选择导出目录（快照默认最新一份；空间类型自动探测，无需手动选择）；
4. 点击「开始恢复」，在「执行」页等待完成——明文笔记以 txt 文件导出到您选择的目录。

## 常见问题

**提示「密码或恢复秘钥不正确」？** 历史快照需要**当时**的凭据：改过密码的用旧密码，重置过秘钥的用旧秘钥。可点提示旁的「尝试上一份快照」自动换上一份重试；密码输错不会损坏数据，可放心重试。

**GitHub / Gitee 打不开？** 两平台内容一致，换另一个平台下载或在线获取即可。

**恢复秘钥丢了？** 空间密码与恢复秘钥同时丢失时数据无法恢复，请在服务停摆前保存好恢复秘钥。

**想恢复更早的数据？** 快照每周五一份、保留最近 10 份（约 10 周），更早的已滚动删除、无法获取。

## 仓库结构

```text
index.json                  # 快照清单（可选快照与校验值）
tool/notebook-restore.exe   # 数据还原工具
checksums/SHA256SUMS        # SHA-256 比对便利副本
snapshots/<日期>/           # 每周五一份快照（manifest.json + data/ 分片）
```
